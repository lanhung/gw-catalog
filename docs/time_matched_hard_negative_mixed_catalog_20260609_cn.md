# Time-Matched Hard Negative 混合 Catalog 实验结果

生成时间：2026-06-09

## 实验设置

- 按 `GW_time_matched_hard_negative_protocol.docx` 设置实验。
- LIGO catalog 内混合 LIGO_SIS + LIGO_PM；ET catalog 内混合 ET_SIS + ET_PM。
- 每个 query 的候选列表包含 1 个真实 counterpart + 200 个负样本。
- `uniform`：负样本从 mixed catalog 随机抽取，用作 catalog 粗筛对照。
- `hard`：负样本要求和真实 pair 的观测时间差匹配，按 `|log10(dt_neg+1)-log10(dt_pos+1)| <= 0.25/0.5/1.0` 逐步放宽。
- 时间特征只使用 `trigger_time_obs`：`log10(|t_i - t_j| + 1)`，没有使用模拟真值时延。
- Reranker 在 validation hard negatives 上训练，再分别评价 uniform 和 hard candidates。
- 分组报告：overall、SIS subset、PM subset、macro-average。
- Top1%/Top5%/Top10% 按候选列表长度 201 计算，分别对应 top2/top10/top20。

## Hard Negative 构造检查

- 每组 test query 数：6000。
- hard test 中有 3523 个 query 需要放宽或 fallback 到最大窗口，说明当前 catalog 时间分布下严格 0.25 dex 匹配并不总能找到 200 个负样本。
- hard test 的 `P(dt_pos < dt_neg)=0.8257`，比 uniform 的约 0.9730 明显更困难，但还没有达到理想的 0.5；后续如果要更严格，应增加 catalog 密度或减少每个 query 的 hard negatives 数量。

## 主要结论

1. hard negative 成功削弱了时间先验：overall `time_only` 在 hard test 中 R@10=0.2037，而不是像 uniform/random 粗筛那样接近满分。SIS 子集尤其明显，R@10=0.0357。
2. ET noisy 在 hard test 下波形仍然很强，`waveform_only` R@10=0.8703，说明 ET noisy 的波形表征有实际确认能力。
3. LIGO noisy 在 hard test 下仍然困难，`waveform_only` R@10=0.2512，`waveform+time` R@10=0.3378；PM 子集比 SIS 子集更高，PM R@10=0.4217，SIS R@10=0.2540。
4. 当前预测 sky_overlap 对 LIGO noisy 帮助有限，`waveform+time+predicted sky_overlap` R@10=0.3305，略低于 `waveform+time` 的 0.3378，说明预测 sky 分数仍会引入噪声。
5. 真实 sky_overlap 仍是 oracle upper bound，hard test 中接近 1.0，不能作为真实部署结果，但能证明可靠天区关联量理论上很有价值。
6. 论文中建议把 uniform mixed catalog 作为粗筛实验，把 time-matched hard negative 作为确认阶段/严格验证实验。
