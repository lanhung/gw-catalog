# SIS+PM 混合 Catalog 检索实验结果（更接近真实场景）

生成时间：2026-06-09

## 实验目的

本次实验不再把 SIS 和 PM 分开建候选库，而是把同一探测器下的 SIS 与 PM 放入同一个 catalog：LIGO catalog 同时包含 LIGO_SIS 和 LIGO_PM，ET catalog 同时包含 ET_SIS 和 ET_PM。这样更接近真实观测目录，因为真实触发事件不会预先告诉我们它属于哪一种透镜模型。

## 数据与评估设置

- ET_SIS 数据：`/root/autodl-tmp/gw_et_10000_matchstyle_20260527_091859`
- LIGO_SIS 数据：`/root/autodl-tmp/gw_ligo_10000_matchstyle_20260527_091859`
- ET_PM 数据：`data_generation/pm_mass_1e4_1e10_td_min24s_matchroots/ET`
- LIGO_PM 数据：`data_generation/pm_mass_1e4_1e10_td_min24s_matchroots/LIGO`
- 每个 detector/mode 训练一个统一的混合编码器，避免 SIS/PM 各自模型 embedding 空间不一致。
- 每组 50 epoch。
- 混合测试 catalog 中 Top1% 对应 k=90，Top5% 对应 k=450，Top10% 对应 k=900。
- 指标：R@1、R@5、R@10、Top1%/Top5%/Top10% recall、中位真实匹配排名。

## 主要结论

1. 混合 catalog 后，ET pure 和 LIGO pure 的波形检索仍然很强，说明纯信号条件下统一编码器能够同时处理 SIS 与 PM。
2. noisy 条件下，ET 的波形仍有明显信息量，ET noisy 波形-only R@10=0.5457；LIGO noisy 波形-only R@10=0.0257，说明 LIGO noisy 的主要瓶颈仍是波形被噪声破坏后可检索信息不足。
3. 只靠时间在所有组里结果相同，R@10=0.5308，Top10%=0.9093。它不是充分判据，但在大 catalog 中是很有效的粗筛信号。
4. 真实 sky_sep 和真实 sky_overlap 的结果接近上限，说明如果天区关联量可靠，它对 catalog-level 检索非常强；但这属于理想可观测辅助信息上限实验。
5. 预测 sky_overlap 当前质量不足，尤其 LIGO noisy 中只靠预测 sky_overlap 的 R@10=0.0005，和波形组合后也没有提升。这说明机器学习估计 sky map/overlap 仍是主要技术瓶颈。
6. 对 LIGO noisy，波形+时间 R@10=0.4620、Top10%=0.9112；波形+时间+预测 sky_overlap R@10=0.3838，没有超过波形+时间，说明当前预测 sky 分数会引入噪声。
7. 对论文来说，这套混合 catalog 比 SIS/PM 分开评估更合理，可以作为主实验；分开评估更适合作为消融或可解释性补充。

## 建议写法

论文主结果建议采用“同一探测器下 SIS+PM 混合 catalog”的设置；同时报告四类对照：只靠波形、只靠时间、只靠 sky、波形+时间+sky。真实 sky_sep/sky_overlap 可作为物理辅助信息上限，预测 sky_overlap 作为真实部署方向的当前结果。需要明确指出：当前 LIGO noisy 的困难主要不是 catalog-level rerank 框架本身，而是 LIGO noisy 条件下波形表征和预测 sky_overlap 的质量不足。
