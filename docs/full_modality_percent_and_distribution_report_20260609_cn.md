# ET/LIGO SIS/PM 多模态检索结果与分布对比（2026-06-09）

本次评估复用已训练的 ep50 InceptionTime-bandpass waveform encoder，不重新训练大模型；对每个 test catalog 做全量排序。

R@1/R@5/R@10 是固定前 K 名命中率；Top 1%/5%/10% 是候选总数百分比阈值。本次 test catalog 的阈值为 Top 1%=45、Top 5%=225、Top 10%=450。

sky 分两种：真实 sky 是用数据表中的 ra/dec 算出的 oracle 对照；预测 sky 是 waveform -> sky unit vector 预测后再计算 Gaussian sky-map overlap。

## 主要结论

1. 只靠真实 sky_sep 或真实 sky_overlap 时，SIS/PM、ET/LIGO、pure/noisy 基本都接近满分，这是 oracle 条件，不代表真实可直接使用。
2. 只靠预测 sky_overlap 效果明显差，尤其 LIGO noisy 下很弱，说明当前 sky 预测模型仍是瓶颈。
3. 只靠时间时，PM 明显强于 SIS：PM 的真实时延远小于随机事件时间差；SIS 时延更长，更容易和随机 catalog 间隔重叠。
4. LIGO noisy 下只靠波形都很差：PM R@10=0.0290，SIS R@10=0.0387，说明 waveform embedding 在 LIGO noisy 下本身区分能力弱。
5. 对 SIS LIGO noisy，真实 sky + 时间能把 R@10 推到接近 1；预测 sky + 时间没有明显提升，甚至弱于只用时间。

### 分布解释

- 源参数和未透镜 SNR 基本一致，说明 SIS/PM 不是源分布不同导致的。
- SIS 的放大率和 lensed SNR 反而更高，因此 SIS 难不是因为信号更弱。
- 最大差异是时延：PM median 约 3.83e4 秒，SIS median 约 3.41e6 秒，相差约两个数量级。
- PM 的 true delay 几乎总是小于随机 catalog 时间差，所以 time-only 很强；SIS 的 true delay 更长，可分性下降，所以只靠时间或时间+预测 sky 对 SIS LIGO noisy 不够。
