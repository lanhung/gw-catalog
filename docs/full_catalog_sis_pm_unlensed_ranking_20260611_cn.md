# Full-Catalog Ranking：SIS + PM + 未透镜混合实验

生成时间：2026-06-11

## 实验设置

- 按 `GW_time_matched_hard_negative_protocol.docx` 的方向调整。
- ET 和 LIGO 分开建 catalog；每个 catalog 同时包含 SIS、PM、未透镜事件。
- 测试阶段不再使用 `1:200` 候选池，而是每个 query 在完整 catalog 中排序。
- Reranker 仍在 validation 的 time-matched hard negatives 上训练，用于避免只学随机时间先验。
- 时间特征只使用 `trigger_time_obs`，没有使用模拟真值时延。
- 真实 sky_overlap 是 oracle upper bound；预测 sky_overlap 是当前可部署特征。

## 主要结论

1. 这次已经是 full-catalog ranking：SIS、PM、未透镜事件在同一个 detector catalog 中一起参与排序，不再是 1:200 限制候选池。
2. ET noisy full catalog 中，`waveform+time` overall R@10=0.6277，`waveform+time+predicted sky_overlap` R@10=0.6272，预测 sky 没有额外提升。
3. LIGO noisy full catalog 是最困难场景，`waveform+time` overall R@10=0.1572，`waveform+time+predicted sky_overlap` R@10=0.1493；PM 子集明显高于 SIS 子集。
4. 真实 sky_overlap 组合仍然很强，说明天区信息理论上有效，但当前机器学习预测 sky_overlap 不足以替代真实 sky map。
5. 后续如果严格按 docx 继续推进，建议补充 ET density stress test，并把 hard negative 匹配从当前 fallback 状态进一步收紧到 P(dt_pos < dt_neg) 接近 0.5。
